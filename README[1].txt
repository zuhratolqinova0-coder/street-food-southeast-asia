STREET FOOD IN SOUTHEAST ASIA — GITHUB PAGES

1. Create a public GitHub repository.
2. Choose Add file > Upload files.
3. Upload all HTML files plus style.css and script.js (not the ZIP).
4. Commit changes.
5. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
6. Wait for the published URL shown under Pages.
